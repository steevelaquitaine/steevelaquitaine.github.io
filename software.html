Research software

Open-source Python packages that turn the methods of my papers into tools: measure what neural populations encode, and how spike sorting biases what we record.

Multigeom

Visualise the geometry of neural representations, where the local stretching of stimulus (e.g. image) space reflects the local contribution of each stimulus to encoded information, in bits

Landing page Documentation Tutorials PyPI Paper

Spikecurate

Curate single units recorded with dense probes from SpikeInterface extractors, using a classifier trained on quality metrics.

Documentation PyPI GitHub Paper

Spikebias

Measure spike sorting biases on dense probe recordings (e.g. Neuropixels) against the ground truth of a detailed biophysical model of the rat cortex.
